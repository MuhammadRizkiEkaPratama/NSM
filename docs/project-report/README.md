# Project report (Indonesian)

This folder holds the project document written for NSM during the internship in
the Network Security division of PT Bumi Siak Pusako (BSP), July–August 2026. It
documents the lab project; it is not an official company document. The text is in
Indonesian.

| File | Content |
|---|---|
| `Laporan-Magang-NSM.pdf` | Full document (PDF) |
| `Laporan-Magang-NSM.docx`, `Laporan-Magang-NSM-v2.docx` | Editable versions |
| `Lampiran-Laporan-Magang-NSM.docx` | Appendix |
| `00-bagian-awal.md` … `07-pustaka-lampiran.md`, `v2-*.md` | Chapter sources in Markdown |
| `gambar/`, `diagram/`, `lampiran-data/` | Figures, diagrams, appendix data |
| `*.py`, `*.js` | Helper scripts used to capture screenshots and assemble the documents |

As stated in the main [README](../../README.md), everything described here ran in a
personal lab (VirtualBox + GNS3) with no connection to any BSP system.
